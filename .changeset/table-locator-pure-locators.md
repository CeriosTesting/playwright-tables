"@cerios/playwright-table": minor

Add `TableLocator`: a type-safe table API that only returns Playwright locators, backed by a `pw-table-v1` custom selector engine. Rows and cells are resolved by header name in the browser on every retry, so locators auto-wait for late headers and rows and survive reordered columns. Also adds `defineTable()`, typed header keys and row conditions (string, RegExp, `equals`/`contains`/`startsWith`/`endsWith`, `oneOf`, `empty`, `predicate`, and the `not`/`anyOf`/`allOf` combinators), `headerKeys()`/`validateHeaders()`, the `toHaveRow`/`toHaveRowCount`/`toHaveHeaders` table matchers and the `toHaveCells` row matcher (exported as `tableMatchers` and a pre-extended `expect`), `registerTableSelectors()` and a ready-made `test` fixture. Also adds column indexes for `cell()`, `column()`, `header()` and `toBeSortedBy` (which also work on tables without header rows), `first()`/`last()`/`nth()` on rows, the `header.stripIconGlyphs` option, the `toJson()` snapshot (with a `minRows` option to wait for loaded rows), the `toHaveRows` table matcher and the `toBeSortedBy` table matcher (text, number and date sorting, a custom `compare`, and an optional `aria-sort` check). `TableLocator` reads `th` and `td` cells in both header and body rows (so row headers don't shift columns), ignores rows and cells of nested tables, and has an `aria` option for ARIA grids. It places cells by `aria-colindex`, joins rows split over pinned containers by `aria-rowindex`, and supports `aria-colspan`/`aria-rowspan`. Like Playwright locators, it finds rows and cells inside open shadow roots, so a web component that renders its table in a shadow root can be the table root. Negated `toHaveRow`, `toHaveCells` and `toHaveRows` assertions wait for the headers and fail on an unknown header, so a typo never passes. In a table without a `<thead>`, leading rows of `<th>` cells in the first `<tbody>` are header rows. A `predicate` that throws fails the row (also inside `not`, `anyOf` and `allOf`), and the matchers report its error.
